# 点屿原创短音 · 3.1.5

12 款内置音效全部由 tools/generate_sounds.py 原创合成，使用 G 大调的统一音高关系与柔和的起音、衰减包络。没有采样、裁剪或复制 Google / Pixel 的官方录音。设计参考 Google Design 关于同一套声音语言与跨感官协调的公开访谈：https://design.google/library/ux-sound-haptic-material-design 。

44.1 kHz、单声道、16-bit PCM，160–400 ms，峰值约 −13 dBFS；每个文件都从零幅度开始、以零幅度结束，避免爆音。应用再按用户设定的独立音量缩放。

柔点、澄光、轻铃、相遇、气泡、花开、涟漪、微风、木语、上扬、落点、和鸣。

推荐：通知「柔点」、待办和计时「轻铃」、设备「相遇」。升级重置内置推荐音色，保留原音量、开关及自定义 WAV 路径；试听单个内置音色不会改变当前选择。

本项目音效为原创，随项目 MIT 许可分发。
