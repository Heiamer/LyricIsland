# 原创提醒音效

这些音效由本项目通过加法合成制作，未使用或抽取 Apple、iOS、macOS 等产品的录音素材。目标是短促、轻柔、克制的提示感。

- `notification-soft.wav`：轻柔双音，通知默认音效；0.64 秒。
- `notification-glass.wav`：较清脆的双音，通知可选音效；0.62 秒。
- `todo-bell.wav`：逐次展开的三音，待办与计时器默认音效；0.98 秒。
- `device-connect.wav`：柔和连接双音，设备默认音效；0.64 秒。

格式均为 48 kHz、单声道、16 位 PCM WAV，开头缓入、尾部淡出，避免突变点击声。音量缩放由 Rust 播放模块处理，不修改 Windows 全局音量。建议通知 35%、待办 45%，均可由用户调整。

文件通过 `include_bytes!` 嵌入 `sound.rs`，无需另外依赖安装目录中的 WAV；用户自定义文件则从本地路径加载。已接入通知、待办、计时器和设备事件。四段内置音效峰值统一为 0.82，保留淡入淡出且无削波。
