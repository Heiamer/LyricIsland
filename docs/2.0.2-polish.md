# 2.0.2 界面与安装修订

本轮基于用户提供的 DotIsle-2.0.2-Source.zip，保留 Rust lyric-tools 构建、打包和验证链路。安装界面采用 Inno Setup 6.7.3 标准向导，数据迁移与可选清理由 Rust lyric-bootstrap 执行。没有恢复旧 C#、Python 或 PowerShell 源码。

| Before | After | Why |
| --- | --- | --- |
| 模块编辑依赖回车或点击画布才提交 | 模块库底部有明确的保存按钮，同时提交正在编辑的名称和时长 | 用户可直接保存，不必猜测失焦行为 |
| 空白画布的内外框同时亮起 | 单层画布边框，落点反馈仅在实际拖入区域显示 | 边界与接收范围一致 |
| 系统状态开关和位置放在通知页 | 集中在灵动岛页的系统状态提示分组 | 功能归属清晰，岛内与屏幕下方均可选 |
| 行高亮有独立圆角，露出白角，抽屉左右留缝 | 统一连续行底色，主面板与抽屉共用相同水平边界 | 选中填色铺满两侧，内容内边距保留 |
| 两个带 A/B 前缀的音乐选项 | 舒展、紧凑、歌词聚焦三个带缩略图的互斥选项 | 用名称和图形说明排版差异 |
| 舒展布局状态在封面下方 | 状态与歌名按实际字体基线对齐，长标题预留状态空间 | 不与名称、歌词互相干扰 |
| 舒展布局歌词偏高 | 原文、副行整体下移 2 DIP，中线两侧分布 | 保留封面与进度条之间的阅读间距 |
| 手动隐藏需要托盘菜单 | 默认启用空白区域上拖隐藏，短拖可取消 | 胶囊和展开卡片使用同一手势 |

| 切歌封面直接替换 | 展开卡片的旧封面翻出、新封面接入 | 280 ms 原位翻动，连续切换从当前形变接续 |
| 封面取色为自写色相聚合 | Material Color Utilities 的 Celebi 量化 → Score 选种子 → HCT TonalPalette（背景 T24、强调 T80 起并保证 4.5:1） | 采用用户指定的 Monet 算法；material-colors 0.4.2 是官方算法的社区 Rust 移植，随源码 vendor |

界面动画关闭时，教程使用静态示意，封面直接切换。教程关闭后停止循环绘制。上拖隐藏只改变显示状态，不暂停音乐或计时；播放按钮、进度条、设置等操作区域不触发该手势。通过托盘或控制中心可重新显示灵动岛。

## 构建

使用 docs/BUILDING.md 中的 Rust 工具链命令。`lyric-tools package` 新增 `--iscc <ISCC.exe>` 参数；也可使用 `INNO_SETUP_COMPILER` 环境变量。编译器只在构建机需要，用户不需要安装它。

源码归档保留 `Rust/crates/lyric-bootstrap/src/bin/*.rs`，不再把源码中的所有 bin 目录误当成编译产物过滤。安装版、便携版、源码和 SHA256 由同一轮 Rust 打包生成。

## 安装与卸载

Inno Setup 使用每用户安装和稳定 AppId，登记 Windows“已安装的应用”，生成标准卸载程序和开始菜单入口。交互卸载默认勾选保留用户数据；取消勾选才清理设置、待办、流程、通知历史、缓存和日志。静默卸载默认保留，明确 `/REMOVEDATA=1` 才删除。

Rust 清理会验证数据所有权和目录链接。程序文件由标准卸载器按安装记录移除，用户在安装目录另存的无关文件不被递归清空。

测试安装器使用独立 `DotIsle.QA...` AppId、独立数据目录及测试管道，不替换用户的正式安装登记或安装指针。

## 验证

运行工作区测试、Rust verify e2e、verify redesign、verify installer，并执行实际界面交互验证。扩展 redesign 验证模块库、三种音乐布局、手势开关和教程标记在重启后保留。

`LyricIsland.exe --integration-preview <目录>` 导出三种音乐布局、封面翻动关键帧及计时/OSD原生渲染图；`LyricIsland.Settings.exe --tutorial` 可直接打开教程用于复查。

此文档描述最终行为与验证方法，实际通过结果以本轮单独生成的验证报告为准。
