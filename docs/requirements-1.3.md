# 1.3 测试版需求

本版先交付测试包，不发布 GitHub，也不触发 1.2.2 用户的自动升级。

- 歌词长度自适应宽度，默认关闭。使用实际字形宽度，保留封面与控制区域，宽度限制并连续平滑变化。
- 收起的灵动岛显示翻译，默认开启：原文在上、中文翻译在下。没有翻译不制造空白第二行。
- 中文双行模式，默认关闭：当前句在上、下一句小字在下，随歌词滚动。存在翻译且翻译开关开启时优先显示翻译。
- 待办页遵循交接资料 apple-design skill 的层次、留白、即时反馈。支持题目、内容、当地日期、24 小时时间、每日重复、编辑、删除及完成勾选。
- 程序运行时检查待办。一次性过期未提醒项目在下次运行时补提醒一次；每日任务只提醒当天，不重放历史日期。每日勾选仅完成当天，下一天重新待办。完成状态与送达标记保存到本地。
- 待办独立于外部应用通知总开关；暂停通知会同时暂停横幅和声音，恢复后检查仍待提醒的项目。应用关闭时不在后台唤醒。
- 通知、待办各自提供音效开关、原创短音选择、音量、试听和自定义本地 16 位 PCM WAV 文件。音效与横幅出现同步，连续消息避免音效重叠。
- 封面取色统一作用于展开背景、播放按钮、进度条和滑块、时间和控制图标、正在播放状态点，合并到现有封面取色设置。默认开启，关闭恢复自定义颜色。确保深色背景与文本/组件的对比度。
- “正在播放”旁的状态点缓慢呼吸，暂停或关闭界面动画时静止。
