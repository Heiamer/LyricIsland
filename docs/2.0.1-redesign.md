# 2.0.1 紧凑布局与安装维护修订

以用户提供的 2.0.1 源码为基线。原有设备分类、鼠标键盘默认关闭、现有开关和后台任务数据继续沿用。

## 设计依据与长期记录

已将 https://github.com/emilkowalski/skills 的15个技能安装到本机技能库。本轮采用 emil-design-eng、apple-design 的规则：接近关系用间距表达、统一视觉轴线、字重与行距组成层级、即时操作反馈、运动可打断并保留速度。网页技术细节不直接搬进原生程序。

| Before | After | Why |
| --- | --- | --- |
| 并排/分区卡片高264/284，分散垂直留白 | 默认高220/236，按钮共用基线，标题/歌手/歌词同一左轴 | 紧凑但保留封面与文字安全间距 |
| 切回并排时忽略实时插值 | 两个方向都使用同一实时几何 | 绘制、点击与进度拖动一致 |
| 反向操作后派生通道重算 | 对初始值及速度作连续校正 | 降低跳帧感与不自然停顿 |
| OSD替换当前岛 | 可选独立下方提示，默认保留岛内 | 不打断持续活动 |
| 流程与番茄钟分立，简单圆环 | 番茄钟内分段切换，原创数字读数、细进度线和计次 | 借鉴信息层级，不复刻手机外观，保留真实业务 |
| 卸载依赖完整登记且默认只留数据 | 缺失登记可修复，卸载明示保留/删除数据 | 可找到、可卸载，并清楚控制数据去向 |

## 设置位置

- 控制中心 → 灵动岛 → 音乐卡片：原有A/B切换保留、仍放最上方。
- 设置 → 外观与动画：流体动画开关保留，关闭仍使用原曲线；界面动画关闭时不做形变。
- 通知 → 设备/系统状态提示 → 提示位置：Island / Bottom，默认Island，保存与重启读取均由原生校验。
- 流程与专注：番茄钟 / 计时器 / 秒表；番茄钟中选择单次 / 流程。原有内部mode和存储兼容，不转写正在运行的数据。
- 音效继续集中在设置的音效页。

## 安装维护

Setup为当前用户写入64位卸载登记，验证显示名、目录、版本与卸载命令；开始菜单含卸载入口。安装版按需修复旧登记，不修改便携版。

卸载器可直接运行，或从Windows应用列表进入。确认页默认保留数据，取消勾选则清理明确归属的数据目录、缓存和日志。自复制后等待原入口退出，仅处理本安装目录的进程和清单文件，不删除其他便携目录或无关文件。遇到路径越界、保护目录、目录链接或归属不明时停止删除，不声称已清理成功。

## 验证边界

以随附验证报告为准；模拟OSD与真实硬件状态分开记录。安装登记测试使用临时键，不能冒充已在用户的Windows设置页完成安装/卸载。

## 数字计时与音乐微调

秒表/计时器改为无表盘、无厚阴影的数字工作区：左侧累计/剩余读数与操作，右侧计次或时长预设。绿色与控制中心强调色统一；暂停和断连不补造时间。番茄钟的正/倒计时切换仅更改读数方向，单次和流程均保留实际进度，默认倒计时，等待阶段仍等待确认。

音乐并排布局原文上移6 DIP，歌手字号11.5降至10，副行与播放状态保持同一文字带；分区布局原文下移4 DIP，原文与副行间隙收紧4 DIP，歌词块与封面/进度条之间分别保留18/16 DIP。

## 按用户标注再次微调（本轮）

| Before | After | Why |
| --- | --- | --- |
| 分区模式播放状态在右上角，标题宽度因此受限 | 状态移到封面下方，标题恢复可用宽度；歌名/歌手间隔3 DIP，整组中线对齐封面中线 | 对应用户画线与圈注 |
| 并排模式的状态与副行使用不同排版基线 | 两者使用相同实际字体基线，歌手上移1 DIP | 小字落在同一条线上 |
| 设置秒表用两个字号的独立元素 | 一个 StyledText 文本行，同字号，只用颜色区分百分秒 | 消除小数部分下坠 |
| 展开计时岛仍使用旧表盘 | 计时器、秒表、单次/流程番茄钟统一数字、细线与固定底部操作 | 和控制中心保持一致 |

本轮仅修改上述布局与对应绘制/命中几何；已有版本的安装、卸载和其他功能修复均保留。计时岛从真实 Timer 状态生成标签和操作，流程等待时显示“下一阶段”，结束后可重新开始；没有目标的秒表不显示虚假的完成进度。

## 系统状态提示入口与弹出层修复

通知页顶部直接提供“系统状态提示”总开关及“灵动岛内 / 屏幕下方”平铺二选一。四种提示不再各有独立开关；旧配置字段作为同一总开关的别名同步，避免界面开启但某一项仍被旧值屏蔽。模拟测试与硬件兼容信息保留在通知设置抽屉。

通用选择菜单移动到整个窗口的最终绘制层，位于抽屉之后，统一使用窗口坐标；靠近右侧或底部时校正位置，上方空间不足时从控件上方展开。菜单遮罩拦截背景点击。
