基于 GitHub v1.1（35f33c9）继续开发，发布版本号为 1.2。保留旧版数据，单文件启动器优先迁移 1.1，再回退迁移 1.0。

## 实现

- 隐藏且无动画时停止提交绘制；稳定展开或收起只绘制可见内容；缓存阴影、渐变与媒体属性。保留刷新率驱动的动画与连续反向操作。
- 修复调色盘外部松手及重新进入时的拖动状态，新增可编辑的十六进制色号输入框。
- GitHub 正式版检查与下载入口；API 限流时使用正式版页面的版本元数据。
- 网易云按歌曲 ID 校验在线详情，补充歌手、专辑及封面。
- 封面取色在解码时执行，过滤近白色并限制背景亮度，只影响展开表面。
- 托盘重启等待旧实例退出；通知启用、暂停和恢复与设置页同步，并显示勾选状态。
- 默认通知接收使用当前用户通知数据库的只读连接，不扫描删除记录，不复制、记录或上传消息正文。只处理启用后的新消息，沿用可选白名单和暂停策略。无变化时缓存查询，读取失败时重试并提示。
- 兼容模式跳过可选身份包，即使分享目录残留旧身份标记。SQLite 与字体随运行包提供，不依赖开发目录或固定用户名。

## 验证范围

- 167 项 Rust 单元和文档测试通过。发行构建成功；第三方 proc-macro-error2 提供 future-incompatibility 提示，应用源码没有新增编译警告。
- 设置七页自检、调色盘拖出松手、色号输入与持久化、托盘暂停切换、重启后数据保留均通过。
- 63 张展开/收起画面与 1.1 逐像素相同。蓝色、红色和纯白封面的取色渲染已检查。
- 隔离 SQLite WAL 数据库验证只读、白名单启停、新消息、去重、坏 XML、暂停和恢复不补弹。
- 真实 Windows 测试通知已由独立解压包接收；接收 EXE 没有包身份，测试没有安装证书或注册通知组件。测试通知使用已存在的发送器产生，发送器和接收器相互独立。
- 同机 32 逻辑处理器、6 秒合成场景：收起播放 CPU 由整机约 0.212% 降至 0.049%，约 165 FPS；隐藏绘制由约 10.7 FPS 降至 0。短样本不代表所有电脑或实际播放器负载；CPU 为 0 表示低于采样精度。

没有在另一台物理电脑或干净 Windows 虚拟机上实测。通知兼容路径依赖 Windows 内部结构与当前用户的正常读取权限；不同系统版本、受限策略或数据库占用可能影响接收，保留系统接口模式作为选项。不能宣称所有电脑都已验证。

当前尚未获得公开受信任代码签名；SignPath 申请材料已整理，尚需维护者联系信息与审核。签名申请不影响默认免证书兼容模式的运行。
