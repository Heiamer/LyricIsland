# 2.0.0 集成与验证说明

此工程从用户提供的 DotIsle-2.0.0-Source.zip 独立解包后修改，没有覆盖原工作目录；发布资产与提交信息见对应发行页。

## 控制中心归属

- 灵动岛：音乐卡片布局位于最上方；尺寸与显示包含歌词进度涂色、歌词涂色跟随封面、双行与宽度上限。
- 流程与专注：模式顺序为流程、番茄钟、倒计时、秒表；新建流程使用模块库、画布、阶段详情。库时间仅影响下一次添加；草稿独立于运行实例。
- 通知与设备：新增默认关闭的通知黑名单；支持勾选已识别应用和输入完整AUMID，与白名单同时开启时黑名单优先，保留既有历史记录。新版图标使用最后确认的柔和拟物带底板版本；启动仍静默建立设备快照。
- 关于与更新：默认自动检查、手动检查、下载更新、查看岛上进度与诊断导出。
- 音效：继续复用现有集中管理，没有把设备音效复制到其他页面。

## 新默认值与歌词颜色

缺失设置时，中文双行、歌词宽度自适应、自动检查更新、耳机/音响/手柄/鼠标/键盘连接及断开提醒默认开启。保留已经保存的 false；不强制覆盖用户偏好。

WordHighlight 控制原文进度涂色；LyricColorFromCover 独立控制该颜色是否跟随封面。频谱跟随最终歌词涂色。翻译与下一句固定使用次要文字色，不应用进度裁切。封面取色未启用时使用固定配置色。

## 流程交互

从拖动手柄拖入复制模块，点击加号也可添加。阶段手柄拖动排序，详情可以改名/改时间/复制/删除，也可用上移下移按钮或画布获得焦点后的 Alt+上下。插槽高亮显示落点，靠边移动支持滚动。原生 GPUI 管理拖动捕获与窗口外取消。

保存/创建期间避免重复提交；后台失败保留草稿。载入模板先确认替换。编辑与重复模块不会改变运行实例。继续使用 2–12 段、每段 1–240 分钟、总时长≤24小时、阶段到期等待明确下一阶段的业务规则。

## 更新与旧版迁移

更新候选在用户确认下载时锁定，保持国内/海外双源；同版本摘要冲突停止替换。真实成功写入字节产生进度；未知长度不生成百分比；校验不是安装完成。主程序显示绿色圆环，无箭头；安装前助手创建独立状态岛，替换后查询新进程真实版本确认启动。

下载/校验后停在待安装，用户点击重启并安装才退出。关闭进度不等于取消下载。自动检查失败静默，手动检查失败可见；自动发现同版每日最多提醒一次。

提供 DotIsle-2.0.0-Setup.exe 安装器，并补充独立 DotIsle-2.0.0-Portable.zip 便携包。后者以 Portable.json 维持便携模式，OTA覆盖后也不触发安装迁移或安装版跳转；数据保存在同目录 Data。选择安装目录，默认当前用户 LocalAppData/Programs/DotIsle，无自动提权。数据放独立用户目录并由 Installed.json 指向。卸载按安装清单逐文件清理，保留用户数据。

OTA-Compatibility 中仍保留 LyricIsland-2.0.0-Portable.zip 与相应 SHA256 清单，这是旧更新器要求的传输格式，必须将这两个附件以原文件名放到未来发行版资产根部。旧更新器先更新原运行目录，新进程发现迁移标记后自动打开安装向导；取消仍可使用更新后的原位置版本。安装完成后，旧启动入口转到已安装版本。原安装目录不会自动删除。新安装存在旧数据冲突时保留已有数据，迁移来源另存 MigrationBackups。

本轮版本仍为2.0.0；不会让已经是同号2.0.0的客户端误判成更高版本。需要测试公开线上自动发现时必须另发更高版本，不能仅覆盖同号附件。

## 诊断容量

单日志约2MiB轮转，最多8份且总量约18MiB，保留不超过7天；连续相同消息15秒合并并计数。清理限本应用日志前缀，不处理其他文件。每个事件截断4096字符；对用户目录、常见令牌/授权字段和URL查询参数做隐藏。

导出只读每份日志最后128KiB、最多8份/来源目录，保留错误摘要和日志尾部、版本/架构、有限配置摘要；最多保留4份导出。不会导出完整配置、通知正文库或待办数据库。自动隐藏不能保证识别任意文本内所有隐私信息，分享前可查看生成的文本。

## 验证范围

工作区测试、真实原生截图、控制中心 smoke、更新字节进度管道、安装器解包/安装/数据迁移以及兼容包校验各有独立报告。真实物理外设接入和另一台电脑/虚拟机的公开网络OTA仍需实机测试，不能用模拟预览替代。
