## 下载与使用

适用于 Windows 10 / 11 x64。请在发行页选择：

| 文件 | 使用方式 |
| --- | --- |
| `DotIsle-2.0.0-Setup.exe` | 安装向导，可自行选择安装目录；数据独立保存在用户目录。 |
| `DotIsle-2.0.0-Portable.zip` | 完整解压到可写文件夹，运行 `LyricIsland.exe`；数据保存在同目录 `Data` 中。 |
| `DotIsle-2.0.0-Source.zip` | 完整源码，含构建、打包和验证脚本。 |
| `DotIsle-2.0.0-SHA256.txt` | 安装器、便携包和源码的 SHA256 校验值。 |

首次运行后，从系统托盘打开控制中心。不要只复制主程序，完整运行需要随包字体、SQLite 和其他组件。

便携版请保留 `Portable.json`，移动时复制整个目录；不会跳转到安装版或主动打开安装向导。安装版和便携版共用单实例限制，切换前先退出当前点屿。

## 2.0.0 更新

- **流程与专注**：流程排在番茄钟之前。模块从左侧库拖入画布，独立修改时长，拖动排序、复制和删除，保存为模板；保留番茄钟、倒计时和秒表。
- **软件更新岛**：自动检查默认开启，发现新版本时提醒；用户确认后下载，绿色圆环显示真实字节进度，校验完成后等待确认重启安装。
- **音乐布局**：两套展开卡片布局重新调整封面、标题、歌词、进度和操作区间距；选择入口位于“灵动岛”页最上方。
- **歌词显示**：中文双行与宽度自适应默认开启；原文参与进度涂色，翻译和下一句保持次要文字色；“歌词涂色跟随封面”独立控制，频谱跟随最终歌词颜色。
- **设备提醒**：耳机、音响、手柄、鼠标、键盘、U盘、硬盘和手机使用统一的柔和拟物图标；各设备连接及断开提醒可单独关闭。
- **通知黑名单**：默认关闭，支持已识别应用与完整 AUMID；同时开启白名单时黑名单优先，排队中的通知也会重新过滤。
- **布局与诊断**：修复设置卡片子项越过圆角的问题；日志按大小、数量与时间轮转，重复信息合并，导出限制读取量并隐藏常见敏感字段。

## 日常功能

播放音乐时查看封面、歌名、歌手、原文与翻译，操作上一首、暂停和下一首。播放控制与歌词获取能力取决于播放器提供的媒体接口。

待办支持标题、内容、日期时间、每日重复、完成状态和配色；流程、专注计时与提醒可投射到灵动岛。多个活动同时运行时，可使用副组件切换。

控制中心集中管理灵动岛、歌词与同步、外观动画、播放器来源、通知设备、音效、待办和流程。设置自动保存；已有用户关闭的选项会保留，不强制覆盖。

## 更新与老版本兼容

更新同时尝试可用更新源，下载失败可切换，校验通过后才替换文件。安装版保留数据目录；便携版保留旁边的 `Data` 和便携标记。

发行附件中的 `LyricIsland-2.0.0-Portable.zip` 和 `LyricIsland-2.0.0-SHA256.txt` 是旧更新器使用的**兼容传输包**，请勿把它当作新的独立便携包。旧单文件版升级后可选择安装目录，取消安装仍可继续运行；旧入口可跳转到已安装版本。1.2.x 旧客户端仅支持其原有更新源，网络不可达时仍需手动下载一次新版。

## 技术与数据

主程序使用 Rust / Win32 / Direct2D / DirectWrite / DirectComposition；控制中心使用 Rust / GPUI 的 DirectX 后端。随包提供 Noto Sans SC、Noto Sans JP 字体和 SQLite，不需要通知证书。

设备连接只读取系统设备状态；充电连接未枚举出设备、厂商错误报告设备类型或系统通知数据库不可用时，部分提醒可能不可用。不会记录鼠标和键盘的操作内容。

日志每份约 2 MiB、最多 8 份，按来源目录限制总量和 7 天保留期；诊断导出有数量与读取范围限制，分享前仍可自行检查文本。

构建说明见 [原生技术文档](NATIVE-README.md)，本轮详细说明与验证边界见 [2.0 集成说明](docs/2.0-integration.md)。
