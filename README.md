# 点屿 · DotIsle

Windows 桌面的灵动岛：音乐与双行歌词、通知、待办提醒、番茄钟、倒计时、秒表和设备连接提醒。

绿色胶囊与状态圆点承载多项活动。点击副圆组件切换；收起和展开都支持左右拖动（默认关闭，可在设置开启）。

下载正式版：[GitHub Releases](https://github.com/Heiamer/LyricIsland/releases/latest)。已有版本可在设置内在线更新，保留配置与待办。

1.3 使用「点屿 · DotIsle」品牌，技术标识继续兼容 LyricIsland。便携包请完整解压后运行 LyricIsland.exe；单文件下载名为 DotIsle-1.3.exe。

详细功能、默认开关和构建说明见 [使用说明](NATIVE-README.md)、[更新日志](CHANGELOG.md) 与 [构建文档](docs/BUILDING.md)。
